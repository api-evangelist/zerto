# Zerto

> Zerto (a Hewlett Packard Enterprise company) provides continuous data protection, disaster
> recovery, ransomware resilience, and multi-cloud data mobility. Its ZVM/ZCA/ZIC appliances
> expose a REST API (/v1) authenticated via an embedded Keycloak OAuth2 provider, used to manage
> Virtual Protection Groups (VPGs), failover/failback, checkpoints, alerts, and long-term retention.

## API

- [Zerto ZVM REST API v1](https://help.zerto.com/): Manage DR programmatically — VPGs, VMs, failover, checkpoints, alerts, events, VRAs, peer sites, LTR. Base URL: https://<appliance-host>:443/v1. Auth: Keycloak OAuth2 bearer (scope=openid).
